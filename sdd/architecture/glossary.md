# Architecture glossary

- **Capability:** a logical ability independent of its implementation.
- **Component:** a concrete module, service, package, UI element or
  infrastructure unit that provides behavior.
- **Profile:** a composable set of architecture concerns and deterministic
  fitness rules.
- **Architecture context:** the bounded, hashed facts and constraints supplied
  to an implementation or advisory agent.
- **Architecture delta:** the evidence-backed difference between an approved
  plan and its implementation.
